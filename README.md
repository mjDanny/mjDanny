## How I approach development

I care about more than making an endpoint return `200 OK`.

When working on a feature, I try to think about:

```text
Business requirement
        ↓
Domain & data model
        ↓
API / integration contract
        ↓
Application architecture
        ↓
Implementation
        ↓
Validation & testing
        ↓
Deployment / operation
```

I actively use modern AI coding tools in development, but treat them as engineering accelerators rather than substitutes for understanding the system. Architecture, trade-offs, code review and responsibility for the result still stay with the developer.
